## Примечания

1. Период Wordstat по «дата платформа»: **19.07.2026 – 17.08.2026**.
2. Частотности `дит` / `дит это` — как на скрине keys.so; запрос `дит` очень широкий и может быть нерелевантен нише.
3. Блок «Шумные запросы» — как на скринах; перед использованием в контенте лучше перепроверить в Wordstat.
4. Строки **не снято** — нужно доснять в [wordstat.yandex.ru](https://wordstat.yandex.ru/) и подставить числа.
