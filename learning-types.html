VFL и HFL: в чём разница

Справочник типов федеративного обучения: определения, таблица сравнения и схемы выбора HFL или VFL.

Два основных типа федеративного обучения

Краткий ответ: HFL (горизонтальный) — одинаковые признаки, разные объекты; VFL (вертикальный) — одни и те же объекты, разные признаки. Ниже — определения и таблица сравнения.

HFL — горизонтальное федеративное обучение

Данные разных пользователей (объектов), но с одинаковыми признаками (столбцами).

  • У вас есть данные о разных пользователях с одинаковой структурой
  • Нужно увеличить объем обучающих данных
  • Данные географически распределены
  • Требуется соблюдение 152-ФЗ «О персональных данных» и других регуляций

  • Рекомендательные системы для разных регионов
  • Модели распознавания речи от разных пользователей
  • Системы обнаружения мошенничества в банках

  • Простота реализации
  • Высокая эффективность
  • Масштабируемость
  • Сохранение приватности

VFL — вертикальное федеративное обучение

Данные одних и тех же пользователей (объектов), но с разными признаками у партнёров.

  • У вас есть данные о разных аспектах одних пользователей
  • Нужно объединить разные типы данных
  • Партнеры имеют разные роли в экосистеме
  • Требуется создание комплексных моделей

  • Объединение данных банка и интернет-магазина
  • Модели для умного города (транспорт + экология)
  • Персонализированная медицина (анализы + симптомы)
  • Финтех-решения (платежи + кредитная история)

  • Богатые данные о пользователях
  • Высокая точность моделей
  • Уникальные инсайты
  • Синергия между партнерами

Как выбрать подходящий тип?

Горизонтальное

Выбирайте обучение на данных разных пользователей, если:

  • У вас есть много данных одного типа
  • Нужно быстро запустить проект
  • Партнеры работают в одной сфере
  • Важна простота интеграции
Вертикальное

Выбирайте обучение на данных одних пользователей, если:

  • У вас есть данные разных типов
  • Нужна максимальная точность
  • Партнеры дополняют друг друга
  • Готовы к сложной интеграции

Политика конфиденциальности

1. Общие положения

Настоящая политика обработки персональных данных составлена в соответствии с требованиями Федерального закона от 27.07.2006. №152-ФЗ «О персональных данных» и определяет порядок обработки персональных данных и меры по обеспечению безопасности персональных данных ООО "ДТ".

2. Цели обработки персональных данных

Персональные данные обрабатываются в следующих целях:

  • Обработка заявок и обращений пользователей
  • Предоставление информации о продуктах и услугах компании
  • Связь с пользователями по вопросам сотрудничества

3. Категории обрабатываемых персональных данных

Мы обрабатываем следующие категории персональных данных:

  • Фамилия, имя, отчество
  • Адрес электронной почты
  • Номер телефона
  • Информация, содержащаяся в сообщениях пользователей

4. Сроки обработки персональных данных

Персональные данные обрабатываются в течение срока, необходимого для достижения целей обработки, но не более 3 лет с момента последнего взаимодействия с пользователем.

5. Меры по обеспечению безопасности персональных данных

Мы принимаем необходимые правовые, организационные и технические меры для защиты персональных данных от неправомерного или случайного доступа к ним, уничтожения, изменения, блокирования, копирования, предоставления, распространения персональных данных, а также от иных неправомерных действий в отношении персональных данных.

6. Права субъекта персональных данных

Вы имеете право:

  • Получать информацию об обработке ваших персональных данных
  • Требовать уточнения, блокирования или уничтожения персональных данных
  • Отзывать согласие на обработку персональных данных
  • Обращаться с жалобами в уполномоченный орган по защите прав субъектов персональных данных

7. Контактная информация

По всем вопросам, связанным с обработкой персональных данных, вы можете обратиться по адресу: privacy@digitrack.com
