Два основных типа федеративного обучения

Выбор типа зависит от структуры ваших данных и целей проекта

Горизонтальное федеративное обучение

Данные разных пользователей, но с одинаковыми признаками

  • У вас есть данные о разных пользователях с одинаковой структурой
  • Нужно увеличить объем обучающих данных
  • Данные географически распределены
  • Требуется соблюдение GDPR и других регуляций

  • Рекомендательные системы для разных регионов
  • Модели распознавания речи от разных пользователей
  • Системы обнаружения мошенничества в банках

  • Простота реализации
  • Высокая эффективность
  • Масштабируемость
  • Сохранение приватности

Вертикальное федеративное обучение

Данные для тех же пользователей, но с разными признаками

  • У вас есть данные о разных аспектах одних пользователей
  • Нужно объединить разные типы данных
  • Партнеры имеют разные роли в экосистеме
  • Требуется создание комплексных моделей

  • Объединение данных банка и интернет-магазина
  • Модели для умного города (транспорт + экология)
  • Персонализированная медицина (анализы + симптомы)
  • Финтех-решения (платежи + кредитная история)

  • Богатые данные о пользователях
  • Высокая точность моделей
  • Уникальные инсайты
  • Синергия между партнерами

Как выбрать подходящий тип?

Горизонтальное

Выбирайте горизонтальное, если:

  • У вас есть много данных одного типа
  • Нужно быстро запустить проект
  • Партнеры работают в одной сфере
  • Важна простота интеграции
Вертикальное

Выбирайте вертикальное, если:

  • У вас есть данные разных типов
  • Нужна максимальная точность
  • Партнеры дополняют друг друга
  • Готовы к сложной интеграции
