Полностью on‑premise. Без привязки к вендору. Собственная сборка Hadoop.

Подробнее

О платформе

Продукт представляет собой полный комплект для быстрого и воспроизводимого развёртывания: установочные бинарники, Ansible-роли для управления кластером, встроенные тесты совместимости компонентов и подробную документацию.

Операционная система

Астра Линукс Воронеж 1.8

Собственные роли Ansible (Infrastructure as Code)

ALD PRO, HashiCorp Vault

Технологический стек

Core & Storage

  • Apache Hadoop 3.3.4 (Custom Build)
  • HDFS (Data Lake)
  • PostgreSQL + Patroni (Meta HA)
  • Delta Lake 2.x (Core)

Compute

  • Spark 3.2.3 + 3.5.8 (Scala 2.12)
  • Hive 3.1.3 (HA)
  • Java 1.8.0 + 11 (jre gosjava)
  • Python 3.11 + 3.13

Orchestration & Streaming

  • Apache Airflow 2.8.0
  • Apache Kafka 2.8
  • CDC (Debezium Server)

Tools & Discovery

  • JupyterHub (Toree)
  • Kyuubi, dbt
  • Bitbucket, Bamboo, Nexus

Надёжность и SRE

Автоматизация Rolling Restart

  • YARN NM: Drain → Wait Containers → Restart → Health Check
  • HDFS DN: Exclude → Maintenance Mode → Restart → Live
  • HA Components: автофейловер ResourceManager и NameNode
  • PostgreSQL Patroni: Reload / Switchover без простоя

Мониторинг и контроль

  • Deep Health Checks (VIP, JMX, Ports, ZK Quorum)
  • Матрица рестартов (restart_matrix)
  • Guardrails: защита от падения N узлов
